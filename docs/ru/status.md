# Статус Продукта

## Назначение Документа

Этот документ честно разделяет:

- что уже реализовано в рабочем контуре;
- что спроектировано;
- что относится к roadmap;
- что нельзя считать готовым для production.

## Публичный Репозиторий

Статус: готов как product showcase.

Этот репозиторий содержит описание продукта, архитектуру, сценарии,
безопасность и roadmap. Он не содержит исходный код и секреты.

## Designed / Спроектировано

- Целевая модульная архитектура.
- Границы AI/OCR-провайдеров.
- Human approval boundary.
- Контракты будущих коннекторов.
- Production security baseline.
- Путь к 1С-экспорту.
- Roadmap по фазам.

## Roadmap / Еще Не Готово Полностью

- Долговременное хранилище оригиналов.
- Off-host backups.
- MFA.
- Расширенные роли и приглашения.
- Политики хранения и удаления.
- Полная юридическая проверка 152-ФЗ.
- Реальные интеграции с 1С, ЭДО, банками, ФНС и email.
- Нормативный RAG с проверенными источниками.
- Масштабирование OCR.
- Руководительская аналитика production-уровня.

## Почему Такой Статус Сильнее

Публичный репозиторий не притворяется полноценным open-source продуктом. Он
показывает продуктовую зрелость: ясную проблему, целевую аудиторию,
архитектуру, ограничения, риск-контроль и план развития.

Для портфолио это выглядит сильнее, чем пустой репозиторий с кодом без
контекста.
