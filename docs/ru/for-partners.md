# Для Партнеров

## Кому Подходит Обсуждение

AI-Бухгалтер интересен, если у вас есть:

- бухгалтерский аутсорсинг;
- несколько клиентов или юридических лиц;
- регулярный поток первичных документов;
- банковские выписки и ручная сверка;
- задачи, сроки и клиентские вопросы в разных каналах;
- желание проверить AI-помощника без потери контроля человеком.

## Формат Пилота

Правильный пилот должен быть ограниченным:

- 1-3 клиента или один внутренний контур;
- один учетный период;
- согласованные типы документов;
- обезличенные или разрешенные данные;
- ручное подтверждение всех AI-предложений;
- измерение baseline до и после.

## Что Нужно Для Обсуждения

Для предметного разговора полезны:

- список типов документов;
- пример банковской выписки без чувствительных данных;
- описание текущего процесса;
- список частых расхождений;
- кто подтверждает решения;
- какие системы используются: 1С, ЭДО, банки, email, CRM;
- ограничения по хранению и передаче данных.

## Что Не Требуется На Первом Шаге

- реальные пароли и токены;
- полный доступ к 1С;
- реальные клиентские документы без согласования;
- массовая интеграция со всеми системами;
- отказ от текущего учетного процесса.

## Цель Пилота

Пилот должен ответить на вопросы:

- экономит ли система время бухгалтера;
- какие документы распознаются надежно;
- какие расхождения находятся автоматически;
- где AI ошибается;
- сколько ручной проверки остается;
- какая архитектура нужна для production.
