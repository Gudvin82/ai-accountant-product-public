# Бизнес-Ценность

## Для Бухгалтера

AI-Бухгалтер снимает часть ручной операционной нагрузки:

- быстрее разобрать входящие документы;
- меньше искать соответствие между платежом и документом;
- видеть спорные поля сразу, а не после ошибки;
- получать черновики проводок и вопросов клиенту;
- работать из одного контекста клиента, а не из набора папок и чатов.

Главная польза: бухгалтер тратит больше времени на проверку и решение, меньше
на ручной поиск и перекладывание данных.

## Для Руководителя Бухгалтерской Группы

Руководитель получает операционную прозрачность:

- какие клиенты в зоне риска;
- у кого не хватает документов;
- где просрочки;
- какие задачи зависли;
- где AI часто ошибается;
- какая нагрузка у бухгалтеров;
- сколько времени уходит на обработку периода.

Главная польза: управление идет по фактам, а не по ручным статусам в
мессенджерах.

## Для Бухгалтерского Аутсорсинга

Для аутсорсинговой компании продукт ценен как слой контроля качества:

- меньше потерянной первички;
- меньше несостыкованных платежей;
- быстрее подготовка к закрытию периода;
- понятная история решений;
- прозрачность для руководителя;
- основа для масштабирования команды без хаоса.

## Для Клиента Бухгалтерской Компании

Клиент получает более понятную коммуникацию:

- вопросы приходят по конкретным документам и операциям;
- меньше повторных уточнений;
- понятнее, что требуется для закрытия периода;
- быстрее обнаруживаются недостающие документы.

## Как Доказывать Ценность

Пилот должен измерять:

- время обработки документа;
- время сверки операции;
- долю принятых AI-предложений;
- долю исправленных OCR-полей;
- число найденных расхождений;
- просрочки;
- стоимость обработки клиента.

Без проверенных pilot metrics продукт не должен обещать конкретный процент
экономии.
