# Evidence Model

## Зачем Нужна Доказательная Модель

В бухгалтерии недостаточно получить "ответ AI". Нужно понимать, почему система
предложила действие, на каких данных оно основано и кто его подтвердил.

Evidence model описывает, из чего состоит проверяемое предложение.

## Состав Evidence Bundle

Каждое существенное AI-предложение должно иметь:

| Элемент | Назначение |
| --- | --- |
| Source document | исходный файл или документ |
| Extracted fields | реквизиты, суммы, даты, контрагент |
| Confidence | уверенность по полям или совпадению |
| Matching context | связанный платеж, документ или операция |
| Rule or source | правило, нормативный источник или логика |
| AI draft | предложенное действие или объяснение |
| Human decision | подтверждено, исправлено или отклонено |
| Audit event | кто, когда и что сделал |
| Version metadata | версия правила, модели или сервиса, если применимо |

## Пример

```text
AI suggestion:
  Предложить проводку Дт 41 - Кт 60

Evidence:
  - УПД N184 от 15.07.2026
  - Контрагент: ООО "Поставка"
  - Сумма: 124 800,00 ₽
  - Связанный платеж: 124 800,00 ₽
  - Confidence: 96%
  - Ограничение: требуется проверка договора
  - Решение: подтверждено бухгалтером
  - Audit event: user, timestamp, action
```

## Что Нельзя Считать Evidence

- просто текстовый ответ AI;
- вывод без источника;
- вывод без confidence;
- вывод без статуса проверки;
- предложение, которое нельзя связать с документом или операцией.

## Польза

Evidence model помогает:

- объяснять решения;
- проверять ошибки;
- обучать процесс на исправлениях;
- готовить экспорт в 1С;
- проводить аудит качества;
- снижать риск слепого доверия AI.
