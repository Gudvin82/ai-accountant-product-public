# Безопасность И Соответствие

## Позиция

AI-Бухгалтер работает с бухгалтерскими документами, персональными данными,
финансовыми операциями и потенциально чувствительной коммерческой информацией.
Поэтому безопасность является частью продукта, а не отдельной технической
галочкой.

## Базовые Требования

- Изоляция клиентов и организаций.
- Роли и права доступа.
- MFA для администраторов и владельцев.
- Секреты вне исходного кода.
- HTTPS и защищенные cookie-сессии.
- Журнал существенных действий.
- Журнал чтения чувствительных данных.
- Валидация загрузок.
- Allowlist AI/OCR-провайдеров.
- Резервные копии и проверка восстановления.
- Incident runbook.

## Данные

Классы данных:

- публичные продуктовые материалы;
- настройки организации;
- клиентские бухгалтерские данные;
- персональные данные;
- первичные документы;
- AI-prompts и AI-responses с чувствительным контекстом;
- секреты и учетные данные провайдеров.

## 152-ФЗ

Для работы с реальными данными в России требуется отдельный контур проверки:

- определить состав персональных данных;
- описать цели обработки;
- настроить хранение и удаление;
- оформить доступы;
- проверить провайдеров и трансграничность;
- вести журнал действий;
- согласовать политику хранения документов;
- подготовить процесс реакции на инциденты.

Этот репозиторий не является юридическим заключением. Он фиксирует
архитектурные требования, которые должны быть проверены юристом и специалистом
по информационной безопасности перед промышленной эксплуатацией.

## AI-Безопасность

AI-слой должен:

- не принимать финальные решения без человека;
- не использовать неизвестные источники для нормативных ответов;
- показывать дату актуальности источника;
- уметь отказываться от ответа;
- сохранять след решения;
- отделять черновик от подтвержденного результата.

## Production Gate

До промышленного запуска должны быть закрыты:

- MFA;
- роли и tenant isolation;
- объектное хранилище;
- off-host backups;
- restore tests;
- политика хранения и удаления;
- аудит доступа;
- проверка провайдеров;
- release decision с доказательствами.
