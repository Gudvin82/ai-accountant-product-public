# Roadmap

Roadmap описывает направление развития, а не публичное обещание сроков.

## Run 0: Публичное Досье И Управляемость

Цель: показать продуктовую глубину и зафиксировать границы.

Статус: выполнено в этом публичном репозитории.

- Описание продукта.
- Возможности.
- Архитектура.
- Сценарии.
- Безопасность.
- Статус.
- Roadmap.
- RU/EN-документация.

## Run 0.5: Trust And Business Layer

Цель: сделать репозиторий понятным не только инженеру, но и партнеру,
руководителю бухгалтерской компании и потенциальному пилотному клиенту.

Статус: выполнено в публичном репозитории.

- Бизнес-ценность.
- Сквозной пользовательский сценарий.
- Evidence model.
- Рыночный контекст.
- Partner pilot guide.
- Упрощенная схема работы в README.

## Run 1: Рабочий Пилот С Реальными Данными

Приоритет: P0.

- Постоянная БД.
- Объектное хранилище оригиналов.
- Роли, приглашения, MFA.
- Журнал действий.
- Резервные копии.
- Проверка восстановления.
- Политика хранения.

Критерий выхода: один пилотный клиент может безопасно хранить и обрабатывать
реальные документы с понятным audit trail.

## Run 2: Измеримая Сверка

Приоритет: P0.

- OCR с координатами и уверенностью по полям.
- Парсинг PDF-выписок.
- Классы расхождений.
- Очередь проверки.
- Подтверждение, исправление, отклонение.
- Метрики качества.

Критерий выхода: бухгалтерская команда может сравнить ручную обработку и
обработку с AI по времени, ошибкам и принятым предложениям.

## Run 3: Операции Команды И Клиентские Запросы

Приоритет: P1.

- Черновики вопросов клиенту.
- Подтверждение отправки.
- Статусы ответа.
- Напоминания.
- Рабочая нагрузка бухгалтеров.
- Просрочки и SLA.
- Руководительский экран.

Критерий выхода: руководитель видит полный цикл без ручной сборки статуса из
мессенджеров и таблиц.

## Run 4: 1С И Интеграции

Приоритет: P1.

- Выбор первой конфигурации 1С.
- Односторонний экспорт.
- Идемпотентность.
- Отчет ошибок.
- Повторная отправка.
- Затем осторожная двусторонняя синхронизация.

Критерий выхода: подтвержденные данные доходят до 1С без ручного ввода и
сохраняют связь с источником решения.

## Run 5: Нормативный AI И RAG

Приоритет: P1/P2.

- Версионируемые источники.
- Даты актуальности.
- Отказ от неподтвержденных выводов.
- Оценка качества ответов.
- Правила риска до LLM-объяснений.

Критерий выхода: AI-помощник не отвечает без источников и не подменяет
профессиональную проверку.

## Run 6: Масштаб И Коммерческий Контроль

Приоритет: P2.

- EDO/email/bank/FNS/CRM-коннекторы.
- Планы и лимиты.
- Unit economics.
- Нагрузка OCR.
- Observability.
- Security drills.
- Отчеты для клиентов и руководства.

Критерий выхода: качество, стоимость, риски и коммерческая модель измеримы.
