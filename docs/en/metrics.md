# Pilot Metrics

## Why Metrics Matter

AI Accountant should prove value with measurable results, not promises. For a
pilot, it is more important to show where the system saves time and reduces
operational chaos than to claim generic "accounting automation".

## Core Metrics

| Metric | What It Shows |
| --- | --- |
| Time per document | whether primary processing is faster |
| Time per reconciliation item | whether manual search is reduced |
| OCR acceptance rate | extracted fields accepted without correction |
| Reconciliation acceptance rate | suggested matches accepted by accountants |
| Discrepancy count | issues found before period close |
| Missing documents | documents detected as missing |
| Overdue tasks | deadline-control quality |
| Client response time | how fast client questions are resolved |
| AI rejection rate | where AI is wrong or not useful |
| Cost per document | OCR/LLM economics per processed item |
| Clients per accountant | effect on team operating capacity |

## Pilot Dashboard

The target pilot dashboard should answer:

- how many documents were processed;
- how many fields were corrected by humans;
- which error classes are most common;
- how many AI suggestions were accepted;
- where accountants had to intervene;
- which clients generate the most manual work;
- how much one client costs to process.

## No Fake Claims

This public repository does not include invented efficiency percentages. The
correct position is:

- define metrics;
- run a pilot;
- collect the baseline;
- compare manual and AI-assisted workflow;
- publish only verified results.
